# 本次与历史一致的低纹理定义

在 R832 的灰度输入 [0,1] 上、模型内部归一化之前计算；不是按匹配置信度或标签划分。

1. 用3×3 Sobel核（每核除以8）求梯度 gx、gy，纹理能量为 gx²+gy²。
2. 在每个原生粗格的零偏移锚点，即 (8x,8y)，取16×16窗口，偏移 [-8,+7]。
3. 只对真实有效图像像素求能量均值，padding不计入分母。图像外边界复制；内部padding的无效Sobel邻居用有效中心像素替换，避免伪边缘。
4. 粗格必须合法、窗口有效像素数大于0、能量有限，且均值 ≤ 0.0001920461654663086，才记低纹理。阈值来自此前冻结的训练标定，本轮没有重估或按结果挑比例。
5. 低纹理窗口锚点沿冻结实现保持 (8x,8y)；GT严格粗格标签另用源格中心 (8x+4,8y+4)。这两种锚点用途不同，未混用。
6. 主召回固定分母还要求中心GT可见、对应目标粗格合法。细点EPE按每个细点自己的源坐标投影，不复用粗格中心GT。

实现：src/texture_budget.py::local_texture，schema=sobel3_scale1over8_window16_offsets_minus8_plus7_valid_v1。
