## R832 历史基线和模块研究依据

旧 Exp-0 使用原生四次精修 RRU4，在第 **32,700 步**通过正常训练机制保存。累计访问 130,800 次，覆盖 130,800 条有向行（1.4759%）和 130,196 个无向对（2.1325%）。历史实际吞吐量 3.212 对/秒，峰值已分配 / 已预留 4.01 / 4.71 GiB，粗几何无效访问 18 次。最后一次验证在 30,000 步。表内为开发场景等权均值。

| --- | --- | --- | --- |
| 0 | 0.000 / 0.000 / 0.390 | 58.641 / 71.759 / 82.139 | 32.94% |
| 10,000 | 0.268 / 0.837 / 1.587 | 61.018 / 74.581 / 84.472 | 39.50% |
| 20,000 | 0.859 / 1.215 / 2.081 | 60.855 / 74.722 / 84.364 | 38.00% |
| 30,000 | 1.136 / 1.811 / 3.138 | 60.182 / 73.392 / 83.305 | 40.62% |

30,000 步相对起点，两域 AUC@10 均提高。MegaDepth 在 20,000 步后的 AUC@10 有所回落，同时低纹理召回在 30,000 步更高，说明两项指标走势并不总是一致。R832 与当前 R640 的分辨率、预算和训练配置均有差异，模块归因采用下述 R640 同预算对照。[R832 归档与验证](legacy_r832/verified.json) · [已保留的完整 checkpoint](legacy_r832/checkpoint_32700.pt)

早期实验为这轮筛选提供了三个可检验的问题。

- **候选和纹理分组。** Phase T 的场景等权差为 0.03060，95% 区间为 [−0.00029, 0.08161]，等预算 S5 未通过。Stage 2 的 100 对诊断中，低纹理源格召回从 53.8336% 升至 61.4543%，其他纹理成功源格净减 4,082。Exp-1A 因此同时检查两组召回、正确目标排名和位姿。
- **精修精度与开销。** Phase 3 核实原版细层步幅 1、窗口半径 3、迭代 4 次。Phase 4 同窗实验中，按真值挑选候选的 <2 px 比例比原细置信度高 8.1946 个百分点。这一差距支持检验新精修头，也给出了理想选择的参考上限。
- **不确定性。** Phase 5 的 NIG 参数 α−1 有 84.9357% 落在下界。历史一步头在该诊断下细阶段耗时 8.83 ms，原生一步为 16.97 ms。速度收益能否延伸到当前全网耗时和两域位姿，需用公平对照验证。二维协方差保留为后续分支。[历史代码、实验路径与统计口径](../../source_audit.md)
