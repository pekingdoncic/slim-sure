# 开发前草案

原权重推理、同权重同预算继续微调、加入单个新机制三个对照层逐项报告。开发验证独立于训练场景和 MegaDepth-1500，专项验证只使用作者开发场景。输入保留全图，纹理阈值使用历史训练校准的 0.0001920461654663086（原生 Sobel/8 能量、16×16 有效邻域）。就 GT 匹配的召回使用固定有效 GT 源格分母，联合报告 EPE 与覆盖率。专项数据没有深度时只评价姿态、极线和空间覆盖。

Phase 01 固定名单、几何和效应门槛。Phase 02 正式训练前冻结实际预算、初始化、各组采样顺序、学习率以及通过显存检查的共同分辨率。合法池按原始行覆盖，另报场景内无向唯一图像对覆盖。每一子池在一个随机排列内无放回；共同预算至少满足逐池遍历。没有完成预算的 run 只记录已访问数量。门槛未过保留负结果，并按依赖关系决策。模型、协议及 checkpoint 哈希冻结后才执行 Phase 08。
